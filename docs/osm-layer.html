reasoning-terrain · the OSM layer

The Second Map

Every check RT had was self-referential: it contradicted a label using the label raster's own geometry, slope and neighbours. It could not tell you that the thing the segmenter called Rendzina is a street — because nothing in a label raster knows where streets are. OpenStreetMap does.

Why

Two problems, one layer

A reasoning unit nobody can point at, and an audit with nothing outside itself to check against.

95,170connected components on the aza AOI — the only spatial unit RT had
98road-bounded blocks over the same ground, 54 of them with street names
28.6%of the ground under a mapped street is labelled Shadow — the segmenter cannot see a street it cannot see
2.08 mbest-fit shift between the two maps on aza: co-registered, so they may be compared

“Region 41,882” is not a place. Analysts reason about blocks — the ground bounded by streets — and about intersections, and that partition already exists in OSM for every populated AOI RT will ever see. Meanwhile RT abstains honestly on rock (UNDECIDABLE-NEEDS-geological-map) but had no reference map for the three things OSM maps well: where the roads are, where the buildings are, and where the water is.

The rule that is never traded away

OSM never edits the label raster. Burning roads into labels is the obvious shortcut, and it destroys the only thing that makes the join valuable — two independent maps you can hold against each other — while importing OSM's errors into RT's output with no way to tell them apart afterwards. The layer is parallel, always.

Ingestion

Six steps, per tile

Not a new solution — a second input to stage 0, on the same footing as the DEM. This is a sequence, so it is numbered.

  1. A0 · ACQUIRE

    Snapshot

    The raster's affine gives a WGS84 footprint; Overpass gives the ways inside it. Written to disk with its query, server and UTC time — that file, not the live service, is what every later run reads.

  2. A1 · PROJECT

    To pixels

    Through the raster's own inverse affine. No transform, no join: a partition of the wrong ground looks exactly like a partition of the right one.

  3. A2 · BURN

    Corridors

    Each way buffered by a width from its own tags. Work is proportional to corridor area, not raster area — and the ST class histogram under every way is accumulated while its mask exists.

  4. A3 · PARTITION

    Blocks

    The complement of the corridor, labelled. Shared OSM node ids give the intersections and the segments between them.

  5. A4 · GATE

    Registration

    A refusal mechanism, not a metric. If the two maps are metres apart, every narrow feature disagrees for georeferencing reasons and the checks do not run.

  6. A5 · INDEX

    Cache

    Cached beside the region and chip indices, keyed on the snapshot's fingerprint — way ids and tag content, so a refetch that changes nothing is a hit and one retagged street is a miss.

Policy

Which map wins, and about what

“OSM is a good way to be a reference for the land, but the ST output is considered latest.” That is two rankings on two questions, not one — and reading it as one gets every check wrong in one direction or the other.

  • OSM — the reference map of the land
  • ST — the latest observation of the ground
The disagreement is about Authority Example Reads as
existenceis there a street or a building here at all OSM OSM maps a street; ST shows no road surface under itThe corridor is taken as real. A segmenter that sees no road has not disproved the street. reference-gap
identitywhich grade, which surface, what is it called OSM a way tagged surface=asphalt under a polygon labelled soilThe closest thing to ground truth this pipeline has for the paved/dirt split, which is otherwise a judgement about texture. identity-conflict
statewhat does that ground look like now ST OSM has a building footprint; ST shows bare rubbleST is the newer fact. Relabelling that polygon House would be RT overwriting an observation with a memory. state-change

Two behaviours this inverted

A mapped building over a polygon ST calls MaralBadlands is no longer grounds for switching it to House — it is a change candidate, and on aza a region 78% under a footprint that switched before the policy keeps its label after it. And an ST road with no OSM way is not an ST false positive by default: ST is the later map, so the first reading is an unmapped track, which makes it a free OSM edit.

Consumption

Where it enters the four solutions

Each is a new input to an existing mechanism, not a new mechanism. None of the four calls a model.

S1

Consistency audit

Which labels contradict their context, slope or geometry — rolled up so one row is one decision, however many regions it covers.

Seven reference check families. The only checks that can contradict a label using something outside the label raster.

  • osm-road-missing · -occluded · -grade · -extra
  • osm-building-missing · -extra
  • osm-water-extra

On aza they take the top of the worklist: 2,248 mapped buildings with no House under them, keyed by what ST said instead, and 40 residential streets with no road surface.

S2

Confusion adjudication

S1 says a region is wrong; S2 says what it is, or refuses. The refusal is the feature.

A fourth evidence term, plus candidates the taxonomy would never offer. A Rendzina polygon on a way tagged surface=asphalt needs PavedRoad on the shortlist; soil-to-road is the distance metric's maximum.

Where OSM is silent the term is None and the score is bit-identical to what it was before the layer existed. That identity is a test, not a hope.

S3

Detection triage

Which units are worth an expensive detector. The model compiles a policy once; a deterministic scorer applies it to millions of units.

Reference features, and a new unit of spend. osm.dist_road, osm.building_frac, osm.n_junctions in the same rule syntax as the class fractions — a settlement prior that is a fact, not an inference from the map being triaged.

And the block replaces the grid square: reviewing “block 84, bounded by شارع النخيل” is a different act from reviewing “chip 1,192”.

S4

Derived products

47 classes plus slope plus season become trafficability, concealment, built fabric, change volatility. (drainage and fire_fuel stood here until they were retired; built fabric and change volatility took their two slots.)

Named overlay terms. A mapped street is passable where the segmenter saw only shadow; a footprint is impassable on it, is cover beside it, counts as built fabric under a Shadow label, and settles the volatility of ground the segmenter left Unclassified.

Every product states what the overlay moved before showing a figure — on aza, 27.5% of pixels, with the street network going from 0.42 to 0.81 mean trafficability.

Addressing

Blocks are built on the AOI, addressed per tile

At aza's 0.122 m/px a 1024² tile is 125 m of ground — a third of a city block. A per-tile partition would invent boundaries at the seam that exist nowhere on the ground.

So a tile does not partition itself; it reports which blocks it covers, with both shares. “This tile is 4% of block 84” and “block 84 is 60% of this tile” are different facts, and quoting one as the other is exactly how a subset answer gets presented as an AOI answer.

Vocabulary

What the class name does not say

TerraRosa is one token. What an analyst means by it is a paragraph — and the class names are the entire interface between a segmenter that learned integers and a model that knows geology.

docs/class_notes.md is Markdown, one section per class, that a domain expert edits without asking anyone. A taxonomy that needs a pull request to correct is a taxonomy that stays wrong.

Four fields are read by code, which is what separates it from a glossary. The rest is prose the model reads — injected only for the classes in play, never as a 47-class wall of text.

  • →confused_with feeds S2's candidate shortlist. A measured confusion beats the taxonomy's guess at which classes are alike.
  • →season gates S6's phenology reasoning.
  • →never becomes a candidate prior — admitted only if it is about geometry, position or physics.
  • →scale replaces S2's guessed area and elongation bands.
  • ?source and confidence are not bureaucracy: four unattributed textbook priors once produced 9,793 false findings on one AOI.

Standing

What is true, and what is still a guess

Known risks

  • !OSM completeness is unmeasured for these AOIs. Every reliability number is a guess, and the defaults are deliberately timid. One day of work — 30 blocks, compared by eye — converts the table into measurements.
  • !aza's class-id mapping is suspect, and the join is what exposed it. Its tiles carry no mapping tag, so they are read with the mapping from the sinai drop. Under it, “marl badlands” is the dominant class inside dense urban blocks and half of all mapped buildings have no House under them.
  • !Class notes are empty. The infrastructure is in; the content is a domain expert's to write.
